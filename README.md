# Full Stack Todo Application

A simple full-stack Todo application built with React, Node.js, Express.js, and SQLite. The application includes user registration, login authentication, and user-specific Todo management.

## 🚀 Features

- User Registration
- User Login
- JWT Authentication
- User-specific Todos
- Add Todos
- Delete Todos
- Logout
- SQLite Database
- React Frontend
- Node.js + Express Backend
- REST API

## 🛠️ Tech Stack

### Frontend

- React.js
- Vite
- React Router
- JavaScript
- HTML
- CSS

### Backend

- Node.js
- Express.js
- JWT
- CORS

### Database

- SQLite
